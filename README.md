### AI-Powered Smart Waste Segregation System

An intelligent waste segregation system that uses computer vision and deep learning to classify waste into four categories and automate physical segregation.

- **Model:** EfficientNet-B0
- **Framework:** PyTorch
- **Test Accuracy:** 97.44%
- **Dataset:** 15,110 images
- **Hardware:** Raspberry Pi 5, Arduino UNO, Servo Motor and NEMA 17 Stepper Motor
- **Categories:** Plastic, E-Waste, Organic and Recyclable
